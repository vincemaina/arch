on arch you get the absolute latest version of every package, which sounds great on paper but actually means you have to fix things yourself a lot. now im not sure i need the absolute latest version of everthing, its not why i chose arch. i chose arch for its minimal, what-you-build-is-what-you-get approach.

some tools like omarchy (which is built on top of arch), make it so that packages lag a month behind, so you're no longer on the bleeding edge anymore.

fedora itself seems to wait something like 6 months.

id like to discuss the pros and cons here, or recency vs stability, and then possibly decide on a timeframe for our packages, to help ensure that whatever we install has had enough time to mature out in the wild, and for people to find and fix any bugs with it.
