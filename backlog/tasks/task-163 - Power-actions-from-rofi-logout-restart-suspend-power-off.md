## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a rofi menu offering log out, restart, suspend, and power off, wired to the correct systemd-logind/loginctl/swaymsg actions. Bind it to a keybinding, register it so tools/shortcuts.sh picks it up, and document it in docs/manual/. This gives the desktop a discoverable, keyboard-driven way to control session/power state without dropping to a terminal.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Add setup/dotfiles/dot_local/bin/executable_power-menu: a rofi dmenu offering Log out / Restart / Suspend / Power off. Log out runs 'swaymsg exit'; Restart/Suspend/Power off run 'systemctl reboot|suspend|poweroff' (logind via polkit, same pattern as ~/.local/bin/bluetooth). Log out, Restart and Power off ask a rofi Yes/Cancel confirmation first (replacing the safety the old swaynag prompt gave); Suspend does not, since it is reversible.
2. Replace the existing $mod+Shift+e binding (currently a swaynag 'exit sway?' prompt) in 50-keybindings.conf with 'exec ~/.local/bin/power-menu', called by absolute path per waybar/sway's PATH pitfall - same binding, so tools/shortcuts.sh picks it up automatically (it derives from checks/sway-bindings.sh, which parses the sway config).
3. Add a desktop entry (dot_local/share/applications/power-menu.desktop.tmpl) so the menu is also reachable from $mod+space, matching every other menu this desktop has (bluetooth, notification centre, etc).
4. Document it in docs/manual/02-the-desktop.md with a '## Power' section (same shape as the existing '## Bluetooth' section) explaining the menu and the confirmation behaviour; the keybinding table itself is generated by tools/shortcuts.sh via {{shortcuts}} in 03-the-keyboard.md, so no hand-written table entry is needed there.
5. Verify live: reload sway config, trigger $mod+Shift+e on a scratch/throwaway output per the desktop-verification skill, screenshot the menu and the confirmation step, confirm swaymsg exit / systemctl calls are the ones actually wired (without actually rebooting the test machine - verify by reading rofi's chosen command path and testing the exec substitution rather than actually powering off).
6. Run checks/sway-bindings.sh (no duplicate binding) and checks/session.sh; fix anything they flag.
7. Finalize: verify acceptance criteria, mark task Done.
