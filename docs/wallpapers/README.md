# Wallpaper candidates

Generated from `setup/dotfiles/.chezmoidata/palette.toml`, so they cannot clash
with the desktop palette the way a downloaded image might.

Deliberately near-black and very low contrast. On a tiling desktop the
background is only ever glimpsed through gaps and around floating windows, so
anything busy is noise that competes with the windows in front of it.

These are candidates, not tracked artwork. Only the chosen one gets committed,
into `setup/dotfiles/` so it reaches the machine like any other dotfile.

| File | Look |
| --- | --- |
| `01-corner-glow.png` | Cyan glow from the top left, faint magenta bottom right |
| `02-diagonal-sweep.png` | A single wide diagonal gradient, plainer |
| `03-low-horizon.png` | Near flat, with a faint glow low on the screen |

Any image works instead — drop one in and it can be wired up the same way.
