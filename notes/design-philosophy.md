# Design philosopy

- resource efficient


## intentional

everything that exists for a reason.
every pre-installed program chosen for this specific system for a good reason.
every shortcut chosen for a reason. if a shortcut isn't being used it gets scrapped.
every process earns its place.


## resource-efficient

following on from the above, every tool and process has been chosen
at least partly based on its efficiency.
every tool is at light as possible while still being able to
serve its purpose.
where possible terminal-based tools are used.


## investments

where ive minimalised and cut features down aggresively in some places,
ive also invested more in others.

- application launcher
- terminal
- waybar

these tools serve as the home for this systeml, its important that they feel intuitive.
the waybar should make it easy to quickly keep tabs on the state of your system e.g.
resource monitoring, notifications, workspace indicators, etc.
in some casese it may also provide quick access to certain core features like caffinate, or the calendar.

the application launcher is designed to be the single entry point for everything.
the place where if you're unsure about where to find something, you can almost certainly find it there.
its the place to open applications, perform quick settings changes (e.g. themes, wallpapers, etc).

and then of course the terminal.
the terminal benefits from a nice zsh shell makes it faster and less manual to use.
much of this system relies on terminal tool, and so investing in the terminal experience
is well worth while.
